# Jiayi Li — Product / UX Portfolio

Personal portfolio website showcasing product design, UX, industrial design, and emerging technology projects.

## Website

[View the live portfolio](https://jiayi-li-design-portfolio.imhansoyi.chatgpt.site)

## Structure

- `dist/index.html` — main website
- `dist/*.css` — visual styles and responsive layout
- `dist/assets/` — project imagery and downloadable CV

## Run locally

Serve the `dist` directory with any static web server, or open `dist/index.html` directly in a browser.
